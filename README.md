# ScreenShot - 轻量截屏工具

基于 WPF (.NET Framework 4.7.2) 的截屏小程序，支持框选屏幕区域和简单标注。

## 功能

- **系统托盘常驻** - 运行后最小化到任务栏右下角
- **全局快捷键** - `Ctrl + Shift + A` 随时触发截屏
- **区域框选** - 全屏遮罩，鼠标拖拽选择截图区域，实时显示物理分辨率
- **标注工具** - 矩形、箭头、直线、画笔、文字
- **撤销** - 支持逐步撤销标注操作
- **保存/复制** - 保存为 PNG 文件，或直接复制到剪贴板
- **4K/高DPI适配** - 正确处理屏幕缩放，截取完整物理分辨率

## 使用

1. 运行 `ScreenShot.exe`
2. 系统托盘出现蓝色图标
3. **触发截屏**：点击托盘图标 或 按 `Ctrl + Shift + A`
4. **框选区域**：在遮罩上拖拽鼠标（`Esc` 取消）
5. **标注**：顶部工具栏选择工具
6. **保存**：点击「复制到剪贴板」或「保存到文件」

## 标注工具

| 工具 | 说明 |
|------|------|
| 矩形 | 红色矩形框 |
| 箭头 | 红色带箭头直线 |
| 直线 | 红色直线 |
| 画笔 | 自由手绘 |
| 文字 | 点击后输入文字 |
| 撤销 | 移除最后一步标注 |

## 构建

```bash
# 使用 MSBuild (Visual Studio 2022)
msbuild ScreenShot.sln /p:Configuration=Release

# 或在 Visual Studio 中打开 ScreenShot.sln 直接编译
```

输出文件：`bin\Release\ScreenShot.exe`（约 25KB）

## 技术栈

- C# / WPF
- .NET Framework 4.7.2
- 无第三方依赖，纯 Win32 API + System.Drawing
